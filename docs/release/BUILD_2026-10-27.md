## Relationship to the frozen RC

- The **frozen RC remains the gate artifact**: commit `0dda444`, tag `v2.0.0-rc`, ZIP SHA-256
  `a6c89880da9c9c7188edaf84199de6892f83e1223c19c0a00e4ad00ad66aa58e`, 9,258,496-byte EXE.
- This build comes from the same source but is **not byte-identical** to it: the EXE is
  10,204,672 bytes against 9,258,496, and therefore the ZIP hash differs. The exact cause of the
  size delta was not investigated; a Rust release build is not reproducible at the binary level
  by default (PE timestamps, build-path and linker variation), and the Tauri CLI invocation here
  is not the one that produced the frozen staging binary. What the gate claims is narrower:
  `GATE_M10_CHECKLIST.md` §5.1 claims the *ZIP* is deterministic **from a fixed staging
  directory**, and `make-portable-zip.cjs` re-confirmed that today.
- No GA tag is created here. `v2.0.0` stays withheld until matrix H passes
  (`docs/qa/LEFTOVER_TASKS.md` L-05). This build is tagged `v2.0.0-build.20261027` to mark the
  provenance of the uploaded artifact without touching the GA decision.

## How to run

Unpack the ZIP anywhere writable and start `ModernToDoList.exe`. No installer, no admin rights,
no network. `Data/` is created next to the EXE (or relocated under the user profile if the
install directory is read-only, per RD-M10-033).

## CI pipeline (added 2026-10-27)

`.github/workflows/release.yml` builds the portable x64 release on **every push** and publishes a
GitHub Release when a `v*` tag is pushed.

| Aspect | Behaviour |
|---|---|
| Runner | `windows-latest`, single job, **no matrix** — x64 only (`x86_64-pc-windows-msvc`) |
| Toolchain | Node 22 + `npm ci`; Rust stable with `Swatinem/rust-cache` |
| Build | `npx tauri build --no-bundle` (no MSI/NSIS: the product ships portable) |
| Architecture gate | the job fails if the produced PE is not machine `0x8664` / magic `0x20B`, so a 32-bit or ARM64 artifact cannot be published by accident |
| Packaging | `scripts/release/make-portable-zip.cjs` — same deterministic builder as the frozen RC |
| Artifacts | ZIP + `.sha256` uploaded per commit, 14-day retention |
| Release | on `v*` tags: `gh release create` (or `upload --clobber` when the release already exists), `--generate-notes`; tags matching `rc\|beta\|alpha\|build` are marked **pre-release**, so the pipeline cannot mint a GA release for 2.0.0 |

CI binaries are **not** byte-identical to local builds — a different runner, cache state and
linker invocation produce a different PE — so each build publishes its own SHA-256 rather than
inheriting the local one. Determinism is still guaranteed per fixed staging directory, which is
what GATE_M10_CHECKLIST §5.1 claims.
